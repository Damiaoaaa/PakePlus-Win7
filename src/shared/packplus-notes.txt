PackPlus / PakePlus 打包说明（首页）

1. 更多配置：勾选「TauriApi」（否则 JS 无法强制窗口全屏）
2. 脚本文件：加入 shared/pake-inject.js（启动即无边框全屏）
3. Electron（ele）版建议 additionalBrowserArgs：
   --touch-events=enabled
4. 窗口建议（右侧/底部露桌面常见坑）：
   - 窗口大小：1080×1920
   - maxWidth / maxHeight 必须很大（如 4320 / 7680），竖屏 maxHeight 绝不能是 1080
   - fullscreen = true，maximized = true，decorations = false，alwaysOnTop = true
   - 可先关掉「窗口保持」，避免还原成半大窗口
   - Windows 显示：1080×1920、缩放 100%；任务栏可自动隐藏
   - 显卡缩放选「全屏/全画面」
   - 笔记本点「浏览」请先关 fullscreen（屏高不够时全屏/超高窗口常像没打开）
   - 浏览无窗口：完全退出 PakePlus 再开（旧预览服务未停会失败）
4. 目录对应：
   - 源码改「首页」→ 同步到 home/config/www
   - 源码改「内容」→ 同步到 content/config/www
   - home/config/man、home/config/inject 属于打包壳配置，不在「首页」目录里
5. 不要依赖 run_command：当前 PackPlus ACL 会拦截该命令
6. 首页与内容屏通过 PeerJS（WebRTC）局域网直连，需能访问外网 STUN（首次建连）
7. 改完配置后重新打包再测

关闭窗口会自动断开 Peer 连接。
中英文在同一页内切换，不会拆掉连接。
